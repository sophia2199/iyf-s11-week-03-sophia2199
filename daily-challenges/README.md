# Daily Challenges — Week 3

Day 1: Terminal-only Project Setup
- Create a folder structure using only terminal commands. Example commands are shown in terminal-exercises.md.

Day 2: Find & Grep Mastery
- Use `find` and `grep` to locate files and search inside them. Example:
  find . -name "*.css"
  grep -r "flex" ./

Day 3: Boilerplate script
- Use scripts/new-project.sh or scripts/new-project.ps1 to generate a starter project.

Day 4: Commit message practice
- Make 5 focused commits with conventional commit messages: feat:, fix:, docs:, style:, refactor:

Day 5: GitHub Profile README
- Create a README.md in your GitHub profile repo with an introduction, tech stack, and contact info.
