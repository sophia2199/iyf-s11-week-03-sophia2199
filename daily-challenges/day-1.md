# Day 1: Terminal-Only Project Setup — Example

Commands you can run to create the structure using only terminal commands:

mkdir -p daily-challenge-1/src/css daily-challenge-1/src/js daily-challenge-1/src/images
mkdir daily-challenge-1/docs
mkdir daily-challenge-1/tests

# create files
touch daily-challenge-1/src/index.html daily-challenge-1/src/css/style.css daily-challenge-1/src/js/app.js daily-challenge-1/README.md

# Verify
tree daily-challenge-1
