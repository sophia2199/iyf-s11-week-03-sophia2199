## How to use
1. Clone this repository:
   git clone https://github.com/sophia2199/iyf-s11-week-03-sophia2199.git
2. Try the bash script (on macOS/Linux or WSL):
   chmod +x scripts/new-project.sh
   ./scripts/new-project.sh my-demo-project
3. Try the PowerShell script (Windows PowerShell / PowerShell Core):
   .\scripts\new-project.ps1 -ProjectName my-demo-project
4. Follow the step-by-step exercises in terminal-exercises.md and git-workflow.md, and paste your real terminal output into terminal-log.md for submission.
